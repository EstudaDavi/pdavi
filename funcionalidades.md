# Estrutura e Funcionalidades (funcionalidades.md)

Construção respeitando a seguinte ordem de prioridade:
1. **Menu de navegação fixo** (com links para as seções e alternador de tema claro/escuro).
2. **Seção Topo / Hero** (Nome em destaque, apresentação e botão Call-to-Action "Ver Projetos" ou "Entrar em Contato").
3. **Seção "Sobre mim"** (com a bio e a lista de habilidades/linguagens: Java, JavaScript, Python, HTML, CSS, Banco de Dados).
4. **Galeria/Grid de Projetos** (cards com imagem, título, descrição curta e link).
5. **Formulário de Contato** (com validação via JavaScript no front-end).
6. **Efeitos de animação suave ao rolar a página** (Scroll Animations).
