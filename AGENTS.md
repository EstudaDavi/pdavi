# Regras para os Agentes de IA (AGENTS.md)

1. Crie o site utilizando apenas HTML, CSS e JavaScript puro (sem frameworks como Bootstrap, React, Tailwind, etc.).
2. Mantenha o código estritamente organizado: um arquivo HTML (`index.html`), um arquivo CSS (`style.css`) e um arquivo JS (`script.js`).
3. O layout DEVE ser totalmente responsivo (otimizado para dispositivos móveis e desktop).
4. Não utilize templates genéricos: siga rigorosamente a identidade visual e as referências listadas.
5. Ao finalizar cada alteração, explique em 2 linhas o que foi feito.
